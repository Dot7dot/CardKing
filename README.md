# CardKing 卡牌王

Draw more and collect more!

一個給手機玩的抽卡收藏遊戲，純 HTML／CSS／JS，直接放在 GitHub Pages 上就能玩。
卡牌資料即時從 [卡牌製造機（card-uploader）](https://github.com/Dot7dot/card-uploader) 讀取：
在製造機新增卡牌或系列後，遊戲重新整理就會出現，不用改程式。

## 玩法

- **第一次打開**送 5 包新手卡包（平均分到各系列）和 200 金幣
- **主畫面**：我的卡片、卡包區、商店區；右上角是持有金幣，金幣外圈的綠色進度條是下一次 +10 的倒數
- **每留在遊戲中 1 分鐘 +10 金幣**（切到背景不計時）
- **商店區**：每個系列一種卡包，各有自己的顏色，一包 100 金幣
- **卡包區**：點卡包 → 卡包放大飛到螢幕前 → 越抖越大 → 自己撕開 → 一張一張翻牌
  - 這包有 **稀有度 ≥ 3** 的卡：撕開時發出**黃金光**
  - 這包有 **稀有度 ≥ 4** 的卡：撕開時發出**彩虹光**
  - 最稀有的卡會留到最後才翻；右上角「全部翻開」可以跳過
- **圖鑑**（在卡包區）：看每個系列解鎖了哪些卡；**每個系列每解鎖 5 張，就送一包該系列的卡包**
- **重複卡**：同一張卡、同一種型態已經有了，就自動換成 10 金幣
- **四種型態**，每張卡抽到時各自擲骰：
  | 型態 | 機率 | 樣子 |
  | --- | --- | --- |
  | 一般 | 55% | 沒有卡面特效 |
  | 金光亮面 | 15% | 金色反光，會隨時間（或手指拖曳）流動 |
  | 霧面 | 15% | 整張卡顆粒感、降低光澤，像磨砂一樣 |
  | 金色邊框 | 15% | 蠟筆畫的金色外框 |

  同一張卡的不同型態都會收進「我的卡片」，點開卡片可以切換型態、按住拖曳看反光。

卡牌外框、卡包、按鈕都是程式即時畫出的蠟筆線條（SVG 濾鏡做出抖動和顆粒），不需要任何圖檔。
音效也是用 Web Audio 即時合成的，右上角 🔊 可以關掉。

## 部署到 GitHub Pages

1. 到這個 repo 的 **Settings → Pages**
2. **Source** 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**
3. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/CardKing/`

用手機開啟後，可以「加入主畫面」當成 App 使用。

## 卡牌資料

- 預設連到 `https://card-uploader.onrender.com/api/cards`，讀取所有卡牌
- 卡牌的 `set`（系列／擴充包）就是卡包的種類；沒填系列的卡會歸到「未分類」
- `rarity`（稀有度）建議填數字 `1`～`5`；也看得懂「普通／稀有／史詩／傳說／神話」
- 稀有度越高越難抽到：抽卡時先依權重決定稀有度（1：100、2：40、3：12、4：4、5：1.5），再從該稀有度的卡裡平均抽一張
- Render 免費方案閒置會休眠，第一次開遊戲可能要等 30–60 秒喚醒；之後遊戲會把卡牌資料存在手機裡，下次打開先用快取、再在背景更新
- 想連到別的卡牌伺服器（例如本機測試）：在網址加上 `?api=http://localhost:3000`

## 調整數值

規則都集中在 `js/data.js` 最上面的 `RULES`：起始金幣、卡包價格、每包張數、重複卡換多少、每分鐘賺多少、
圖鑑幾張送一包、黃光／彩虹光的稀有度門檻。抽卡權重是同一個檔案裡的 `RARITY_WEIGHT`，型態機率是 `VARIANTS`。

存檔在瀏覽器的 localStorage（`cardking.save.v1`），清除網站資料就會重新開始。

## 檔案

```
index.html        頁面骨架、共用的蠟筆 SVG 濾鏡
css/style.css     所有樣式（卡牌、三種型態特效、開包舞台）
js/main.js        畫面切換、首頁、我的卡片、卡包區、圖鑑、商店、金幣計時
js/data.js        連線卡牌資料庫、存檔、抽卡規則
js/opening.js     開卡包動畫
js/crayon.js      蠟筆風的卡牌、卡包、卡背繪製
js/particles.js   彩紙／星星粒子
js/sfx.js         合成音效
```
